# Appeals

This repository is the public record of appeal decisions on Monocle Network.

Appeals allow peers to have an arbitrator's decision reviewed by a different arbitrator. Every appeal decision is recorded here, so the community can see how disputes are handled and hold arbitrators accountable.

This repository contains appeal records only. Appeals are not filed here - see [How to file an appeal](#how-to-file-an-appeal) below.

## What each appeal record contains

For every appeal, the record includes:

- The trade ID
- The original arbitrator that was assigned
- The reviewing arbitrator that was selected
- The outcome of the appeal (upheld, overturned, or modified)
- The rationale for the decision
- Whether the appeal deposit was returned
- Whether any documents were updated as a result of the appeal (e.g., trading rules or the table of penalties)
- The payout transaction details for any compensation made
- The payout transaction details for any return of the appeal deposit

## Privacy

No peer identifying information is published in any appeal record. Peer identities, trade details, and evidence remain confidential.

The original arbitrator is identified in the appeal record. This ensures accountability and consistency across cases.

## How to file an appeal

Appeals are not filed in this repository.

To file an appeal, contact a chosen reviewing arbitrator via SimpleX Chat, pay the appeal deposit, and provide the trade ID and supporting documentation - within 7 days of the payout transaction. The full process, including the deposit, the review, and outcomes, is defined in the [Appeals Policy](https://monoclenetwork.org/appeals-policy).

## How to verify

- Review the appeal record in this repository, using the trade ID to reference the original dispute
- For any compensation or returned deposit, check the published payout transaction ID and secret transaction key against the Monero blockchain
- Confirm the transaction was sent from the Monocle Network fee address, which anyone can audit using its published view key (see [Transparency](https://monocle.wiki/Transparency))
